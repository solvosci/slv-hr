Allows setting expense configurations per employee, company, and product
combination.

Also, configuration for a product for a certain employee becomes
required; otherwise that product cannot be selectable for an expense.

Known issues / Roadmap
======================

If a menu “Expense product configurations" is added in the future, add
the following rules:

- Regular employees can only see their own expense configuration.
- Expense approvers can see all configurations
